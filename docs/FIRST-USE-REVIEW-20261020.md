# First-use heuristic review — 2026-10-20

This is an engineering review using actual processing/output workflows and automated layouts. No representative participants, observed completion times, screen-reader sessions, Android device sessions or actual printer tests were available. The roughly ten-second starting-action target remains unmeasured.

All five starts are present on an empty-history home screen or its labelled tool entrances; search includes common synonyms, including straighten/deskew. Search/widget evidence is not an observed discoverability time. Core and responsive checks do not establish that every first-time user will succeed without instructions.

Remaining usability work: representative users with varied technical experience; keyboard-only complete journeys; real screen readers; localization and Bangla interface strings; Android document-provider/camera cancellation and recreation; drag-and-drop; open/share/reveal actions after saving; retention comprehension; clean systems and actual printers. Record observations and iterate rather than declaring universal ease of use.
