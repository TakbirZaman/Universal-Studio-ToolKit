# Full-scope phased plan
1. Repository, dependency resolution, domain types, validation, safe exports, reference fixtures.
2. Photo processing and PDF page operations with output verification; Flutter/Riverpod/FRB vertical slices.
3. PDFium previews and appearance comparison; Android document-provider export; desktop runtime packaging.
4. Scanner camera and non-destructive sessions, OpenCV geometry, quality advisories, retention/recovery.
5. Full photo editing, manual signature refinement, physical dimensions, flexible compression, print UI and batch/recipe persistence.
6. Application pack slot constraints, integrated managed sources, report/manifest export, selective retry.
7. Tesseract English/Bangla verified assets, editable OCR; geometry-validated searchable PDFs; face assistance.
8. Remaining PDF watermark/numbering/signature/form operations, compression modes; structure interoperability.
9. Accessibility, visual and real-user tests, localization, security/resource tests, license audit, clean-device release gates.

Work progresses without phase-by-phase approval. No phase is deemed complete from this plan alone.
