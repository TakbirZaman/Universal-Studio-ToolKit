Windows x64
Extract the complete Windows ZIP into a new folder. Run universal_studio_toolkit.exe from that folder. Keep the bundled DLLs and data folders beside it.

Linux x64
Extract the tar.gz into a new folder. Open the directory containing universal_studio_toolkit and run ./universal_studio_toolkit. This build was tested on Ubuntu 24.04 x64 and needs a compatible GTK3 runtime. Clean-system and AppImage acceptance remain unfinished.

Android ARM64
Install the Android APK. It is an optimized development build with a disposable signing identity. An older development install may use a different key and may need to be removed first. Export saved presets as JSON and save scan drafts as PDFs BEFORE removing an older install: uninstalling removes local app data. Stable production signing and update distribution remain unfinished.

What changed
After preparing a photo, signature or photo recipe, choose Compare images. Switch Original/Prepared; zoom, pan and Reset zoom inspect the bounded preview without changing saved bytes. Preview conversion is limited to 1200 pixels and zoom to 8x; full-resolution comparison remains future work. Switching sides resets the fitted view. The OCR preview now grows to accommodate its controls and enlarged text.

Application packs retain ready results when another document fails. Retry the affected document or prepare unfinished documents. Stop waits for the current operation and preserves its successful result; resume reuses ready results. Repair a selected optional source or explicitly clear it to omit that slot. Sources and prepared results have separate 64 MiB encoded-byte quotas and remain session-only.

Validation
All twelve workflows passed on this source. Native suites: 95 Linux / 93 Windows. Flutter suites: 75 Linux / 72 Windows, with three platform-specific Windows skips; Linux visual captures also pass. Packaging and hosted desktop launch checks passed. Real-device/provider/printer/screen-reader acceptance remains outstanding.

Remaining work includes broader pack policies/recipes/folder export, advanced PDF/signature tools, persistent managed documents, Windows/Android OCR and searchable PDF geometry, localization/accessibility, process isolation and complete distribution obligations.
