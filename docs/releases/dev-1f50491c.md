## Universal Studio Toolkit — development preview

Verified source: [`1f50491c`](https://github.com/TakbirZaman/Universal-Studio-ToolKit/commit/1f50491c5cbf0f92c89e8a76e9387b2824e39b7d). Includes original/prepared image comparison, preview zoom and pan, selective application-pack retry, saved presets, visual cropping, photo flips and PDF split groups.

### Downloads

- Windows x64: extract the complete ZIP and run `universal_studio_toolkit.exe`.
- Linux x64: extract the bundle and run `./universal_studio_toolkit`. Built on Ubuntu 24.04; requires a compatible GTK3 runtime.
- Android ARM64: install the development APK. Its signing identity is disposable. Export presets and scan drafts before uninstalling an older build to resolve a signing mismatch; uninstalling removes app-local data.

Read `INSTALL.txt` and verify your download against `SHA256SUMS`. Platform archives retain their bundled third-party notices.

### Development status

Windows/Android OCR, searchable PDFs, advanced PDF/signature tools, persistent managed documents, localization and worker isolation are still in development.
