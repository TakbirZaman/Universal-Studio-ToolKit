# Versioned photo reflection controls

2026-10-22. Photo recipes add optional horizontal and vertical reflection. Version4 introduces exactly one flip step after the optional original-pixel crop and before resizing/compression. Existing versions1–3 retain their previous serialized settings and behavior. Recipes with no enabled flip continue to use their existing minimum schema version. Older native versions reject version4 instead of silently ignoring the operation.

Horizontal mirroring uses the existing guarded photo pipeline's horizontal reflection. Vertical reflection is a half-turn followed by horizontal reflection; both directions together are a half-turn. The composition happens after EXIF orientation correction and cropping, so visual crop coordinates remain in corrected-original pixels. Subsequent resizing, flexible compression, byte constraints, PNG/transparency handling, metadata policy and export validation remain in the existing processing path. Originals are retained unchanged. No face processing, arbitrary rotation or signature-mask refinement is added.

The recipe editor includes both switches, captures them in exported/saved/batch settings, restores them on import/load and clears old prepared results when changed. The interface reminds users to review mirrored text and signatures. Crop preview selection itself continues to show the original; the prepared result shows the reflection. Transform settings from other workspaces are not implicitly inherited.

Native tests independently map every output pixel for horizontal/vertical/both directions, with and without cropping, against the same non-reflected pipeline output. This preserves the existing pipeline's transparent-pixel normalization policy. EXIF tests compare opaque corrected-source pixels directly. Validation rejects old-schema flips, empty flags and invalid step order. Hosted interface tests save/reopen actual PNGs and compare all decoded pixels, export version4 settings and invalidate prior results at100%/200% text. Full platform, regeneration and regression checks gate integration.
